# سعودي AI — نسخة مستقلة (بدون Claude.ai)

موقع وخادم بسيط تملكه أنت بالكامل: نفس أداة بناء التطبيقات والمحادثة، لكنها
تستخدم مفتاح Anthropic API الخاص بك بدل الاعتماد على حساب Claude.ai لكل زائر.

## 1) احصل على مفتاح API

1. افتح console.anthropic.com وأنشئ حسابًا (هذا **منفصل تمامًا** عن اشتراكك في Claude.ai).
2. من API Keys أنشئ مفتاحًا جديدًا (يبدأ بـ `sk-ant-...`).
3. هذا مفتاح **مدفوع حسب الاستخدام** — راجع صفحة الأسعار على نفس الموقع قبل النشر على نطاق واسع.

## 2) جرّبه على جهازك أولًا (اختياري لكن يُنصح به)

```
cp .env.example .env
# افتح .env وضع مفتاحك في ANTHROPIC_API_KEY
npm install
npm start
```

ثم افتح `http://localhost:3000` في المتصفح.

## 3) انشره على الإنترنت

أبسط خيار مجاني هو **Render.com**:

1. ارفع محتويات هذا المجلد إلى مستودع جديد على GitHub.
2. في Render: **New → Web Service** واربطه بالمستودع.
3. Build Command: `npm install` — Start Command: `npm start`
4. من تبويب **Environment**، أضف:
   - `ANTHROPIC_API_KEY` (إلزامي)
   - `ACCESS_CODE` (مستحسن بقوة — رمز سرّي من اختيارك)
   - `ANTHROPIC_MODEL`، `RATE_LIMIT_PER_HOUR` (اختياريان، القيم الافتراضية جيدة)
5. اضغط **Deploy**. بعد بضع دقائق ستحصل على رابط دائم مثل `your-app.onrender.com`.

بدائل مشابهة: Railway.app أو Fly.io.

## ملاحظات مهمة قبل مشاركة الرابط

- **بدون `ACCESS_CODE`**، أي شخص يعرف الرابط يستطيع استخدام الأداة والتكلفة
  تُخصم من حسابك في Anthropic مباشرة. عيّن رمزًا وشاركه فقط مع من تثق به،
  أو مع عملائك مقابل الخدمة.
- يوجد حد افتراضي **20 طلبًا/ساعة لكل زائر** (`RATE_LIMIT_PER_HOUR`) يقلل مخاطر
  إساءة الاستخدام، عدّله حسب حاجتك.
- الخطة المجانية في Render قد "تنام" بعد فترة عدم استخدام، فأول طلب بعدها
  يكون أبطأ بضع ثوانٍ.
- لا يوجد بث حي للنص أثناء الكتابة (streaming) في هذه النسخة، تظهر النتيجة
  دفعة واحدة بعد اكتمالها — تبسيطًا وموثوقية أعلى. يمكن إضافته لاحقًا عند الحاجة.
- مشاريعك والتطبيقات التي تبنيها تُحفظ في متصفح كل زائر (localStorage)،
  وليس على الخادم، تمامًا كما كانت في النسخة السابقة.
